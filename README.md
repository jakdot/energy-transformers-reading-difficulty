# energy-transformers-reading-difficulty

This repo accompanies the paper: Jakub Dotlacil and Ece Takmaz (2026). Energy-Based Transformers as Predictors of Reading Difficulty. https://doi.org/10.48550/arXiv.2606.23382

# Notebooks

Notebooks create data files for the analysis. To run the notebooks, you need to download NRGPT from Huggingface, at bsaha205/NRGPT-H-FF2W-128M-OWT. Or you can train your own NRGPT model, see the NRGPT paper for details.

# Analysis (qmd) files

These can only be run after the notebooks were run and energy and surprisal measures were collected for psycholinguistic data.
