# Data

This folder includes three datasets:

- frank\_etal: The UCL corpus, with unigram and bigram information added (Frank et al., 2013, doi: https://doi.org/10.3758/s13428-012-0313-y)
- memory-for-prediction: The relative clause data, taken and slightly modified (Ryu et al., 2025, https://doi.org/10.1016/j.jml.2025.104670)
- nsc\_data: The natural stories corpus (Futrell et al., 2021, doi: https://doi.org/10.1007/s10579-020-09503-7)

If you use any of these, cite the original sources.
